# warikan-app

シンプルな割り勘計算アプリです。**ログイン不要**で、ブラウザで `index.html` を開くだけで使えます。

## 機能

- 合計金額を人数で割って1人あたり金額を計算
- 端数処理（1円単位で切り上げ）
- 余り金額（回収合計 - 元の合計）を表示
- 入力バリデーション（合計金額・人数の範囲チェック）
- 利用規約・プライバシーポリシーページ

## 使い方

1. `index.html` をブラウザで開く
2. 合計金額と人数を入力
3. 「計算する」を押す（端数は1円単位で切り上げ）
